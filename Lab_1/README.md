# Geometry Application - Lab 1

Приложение для анализа геометрических фигур (треугольников и кубов) с чтением данных из файлов, валидацией и расчетом геометрических свойств.

## 🎯 Описание классов и архитектуры

### 📐 Entities (Сущности)

#### `Shape` (абстрактный базовый класс)
- Базовый класс для всех геометрических фигур
- Содержит общие свойства: `id`, `name`
- Абстрактные методы: `getArea()`, `isValid()`, `toString()`

#### `Point2D` / `Point3D`
- Представляют точки в 2D/3D пространстве
- Методы: `equals()`, `toString()`
- Immutable объекты (readonly свойства)

#### `Triangle`
- Наследуется от `Shape`
- Свойства: три точки `pointA`, `pointB`, `pointC`
- Методы:
  - `getArea()` - площадь треугольника
  - `getPerimeter()` - периметр
  - `isValid()` - проверка на валидность (не колинеарные точки)
  - `getSides()` - длины сторон

#### `Cube`
- Наследуется от `Shape`
- Свойства: `center` (Point3D), `sideLength`
- Методы:
  - `getArea()` - площадь поверхности
  - `getVolume()` - объем
  - `isValid()` - проверка валидности
  - `getVertices()` - все 8 вершин куба

### 🏭 Factories (Фабрики)

#### `ShapeFactory` (абстрактная)
- Базовая фабрика с общими методами
- `createShapeFromString()` - парсинг из строки

#### `TriangleFactory`
- Создает треугольники из массива строк
- Валидирует входные данные (6 координат)
- Проверяет на колинеарность точек

#### `CubeFactory`
- Создает кубы из массива строк
- Валидирует координаты центра и длину стороны
- Проверяет положительность длины стороны

### 🔧 Services (Сервисы)

#### `FileReaderService`
- **Назначение**: чтение и обработка файлов с данными
- Методы:
  - `readFile()` - чтение файла, фильтрация пустых строк
  - `validateFileExists()` - проверка существования файла

#### `TriangleService`
- **Назначение**: анализ и вычисления для треугольников
- Методы:
  - `calculateArea()`, `calculatePerimeter()` - базовые вычисления
  - `isRightTriangle()` - проверка на прямоугольность
  - `isIsoscelesTriangle()` - проверка на равнобедренность
  - `isEquilateralTriangle()` - проверка на равносторонность
  - `getTriangleType()` - тип по сторонам (scalene/isosceles/equilateral)
  - `getAngleType()` - тип по углам (acute/right/obtuse)
  - `getTriangleAnalysis()` - комплексный анализ

#### `CubeService`
- **Назначение**: анализ и вычисления для кубов
- Методы:
  - `calculateSurfaceArea()`, `calculateVolume()` - базовые вычисления
  - `isBaseOnCoordinatePlane()` - проверка расположения на координатных плоскостях
  - `calculateVolumeRatioByPlane()` - соотношение объемов при разрезе плоскостью
  - `isCube()` - валидация объекта как куба
  - `getCubeAnalysis()` - комплексный анализ

### ✅ Validators (Валидаторы)

#### `TriangleValidator`
- Валидация входных данных треугольников
- Проверка колинеарности точек
- Парсинг координат

#### `CubeValidator`
- Валидация входных данных кубов
- Проверка положительности длины стороны
- Валидация результатов вычислений

### 🚨 Exceptions (Исключения)

- `ValidationException` - ошибки валидации входных данных
- `FileProcessingException` - ошибки обработки файлов
- `InvalidTriangleException` - некорректные данные треугольника
- `InvalidCubeException` - некорректные данные куба

## 💾 Формат входных данных

### Треугольники (`data/triangles.txt`)
Каждая строка содержит 6 координат: `x1 y1 x2 y2 x3 y3`
```
0 0 3 0 0 4          # Прямоугольный треугольник 3-4-5
0 0 1 0 0.5 0.866    # Равносторонний треугольник
0 0 2 0 1 1          # Равнобедренный треугольник
```

### Кубы (`data/cubes.txt`)
Каждая строка содержит 4 значения: `x y z sideLength`
```
0 0 0 2              # Куб с центром в начале координат, сторона 2
1 1 1 1.5            # Куб с центром (1,1,1), сторона 1.5
-2 3 1 3             # Куб с центром (-2,3,1), сторона 3
```

## 🔄 Алгоритм работы приложения

1. **Инициализация** - создание всех сервисов и фабрик
2. **Обработка треугольников**:
   - Чтение файла `data/triangles.txt`
   - Парсинг каждой строки через `TriangleFactory`
   - Анализ через `TriangleService`
   - Логирование результатов
3. **Обработка кубов**:
   - Чтение файла `data/cubes.txt`
   - Парсинг через `CubeFactory`
   - Анализ через `CubeService`
   - Логирование результатов
4. **Обработка ошибок** - некорректные строки пропускаются с предупреждением

## 📊 Логирование

Все операции логируются с помощью библиотеки `pino`:
- Успешные операции - уровень `info`
- Пропущенные некорректные строки - уровень `warn`
- Ошибки - уровень `error`

Логи сохраняются в папку `logs/` и выводятся в консоль в читаемом формате.
